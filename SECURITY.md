# Security and research scope
This starter runs offline models only. It does not authorize testing external systems.
Do not submit real payment data, secret keys, raw HAR files or merchant vulnerabilities in public issues.
Use GitHub private vulnerability reporting if the repository owner enables it. Otherwise contact the owner privately through an agreed channel; no disclosure address is configured yet.
Keep verified findings private until a coordinated disclosure plan is agreed with the affected owner. A proposed 90-day remediation window is negotiable, not an automatic publication deadline.
