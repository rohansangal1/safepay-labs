# Image and font sources

Every image and font on the public site is stored here and served from our own domain. Nothing
is hot-linked. Add a row whenever a file is added.

| File | Source | Version | Licence |
|---|---|---|---|
| `icons/*.svg` | [Lucide](https://lucide.dev) (`lucide-static`) | 1.49.0 | ISC |
| `brands/stripe.svg` | [Simple Icons](https://simpleicons.org) (`stripe`), not currently shown | 16.33.0 | CC0-1.0 |
| `brands/square.svg` | [Simple Icons](https://simpleicons.org) (`square`), not currently shown | 16.33.0 | CC0-1.0 |
| `fonts/inter-latin.woff2` | [Inter](https://rsms.me/inter/) by Rasmus Andersson, latin subset as served by Google Fonts | v20 (variable, 400–800) | OFL-1.1 |
| `fonts/instrument-serif-latin-400-normal.woff2` | [Instrument Serif](https://github.com/Instrument/instrument-serif) by Instrument, latin subset via [Fontsource](https://fontsource.org/fonts/instrument-serif) (`@fontsource/instrument-serif`) | 5.3.0 | OFL-1.1 |
| `fonts/instrument-serif-latin-400-italic.woff2` | As above, italic | 5.3.0 | OFL-1.1 |
| `favicon.svg` | Drawn for this project | | Apache-2.0 |

The 3D line illustrations are drawn at runtime by `public/scenes.js`; there are no image files for them.
